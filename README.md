# Painel de Ideias

## Sobre o projeto

O Painel de Ideias é uma aplicação feita em React para adicionar, concluir e remover ideias.

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- CSS

## Como executar

1. Abra o terminal na pasta do projeto.
2. Execute `npm install`.
3. Execute `npm run dev`.
4. Abra o endereço mostrado no terminal.

## Funcionalidades

- Adicionar uma ideia.
- Impedir o cadastro de ideias vazias.
- Marcar uma ideia como concluída.
- Riscar as ideias concluídas.
- Remover uma ideia.
- Mostrar a quantidade de ideias no painel e de ideias concluídas.

## Decisões do projeto

O projeto utiliza componentes funcionais e o hook useState para controlar as informações da aplicação.

A lista de ideias é atualizada sem alterar diretamente o estado anterior.
